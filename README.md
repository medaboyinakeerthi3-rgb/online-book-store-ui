# 📚 Online Book Store UI

## Description

The Online Book Store UI is a responsive web application that allows users to browse a collection of books through a clean and modern interface. It displays book titles, prices, and an **Add to Cart** button, making it an excellent front-end project for practicing HTML and CSS.

## Features

* Responsive user interface
* Displays multiple books with images
* Shows book titles and prices
* Add to Cart buttons
* Simple and attractive layout
* Easy navigation and user-friendly design

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
online-book-store-ui/
│── index.html
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
